# 陪练棋盘 · Android 版

一款六合一棋类练习 App：**围棋**、**五子棋**、**象棋**、**军棋**、**2048**、**数独**。

An all-in-one Android app for six board games: **Go**, **Gomoku**, **Xiangqi** (Chinese chess), **Junqi** (Army chess), **2048** and **Sudoku**.

---

## 游戏

| 游戏 | 说明 |
|---|---|
| **围棋** | 9 / 13 / 19 路，三档棋力可切换，支持人机对弈、自动对弈与逐手复盘 |
| **五子棋** | 13 / 15 / 19 路，可开关禁手，「我执」黑或白 |
| **象棋** | 标准 10×9 棋盘，三档棋力，人执红先走 |
| **军棋** | 全面重做：暗棋 / 翻棋，标准规则（铁路滑行、行营保护、山界、大本营），三档棋力 |
| **2048** | 4×4 数字合并，四方向滑动 |
| **数独** | 9×9，简单 / 普通 / 困难三档，困难档极难 |

## 功能

- **人机对弈**：选好难度就能下，非法手会提示原因，不会闷着不响应。
- **自动对弈**：让 AI 自己跟自己下，一手一手实时看。
- **逐手复盘**：对每一手之前的局面重新分析，给出胜率曲线、失误排行和推荐点，直接看出哪一手输了。
- **悔棋 / 停一手 / 认输**：悔棋会整体重算盘面，不是简单回滚。
- **棋谱**：终局自动保存；也能用系统文件选择器读入棋谱继续下或直接复盘。
- **学习你的习惯**：军棋、五子棋、象棋都会记录对局中的局面与胜负，越下越顺手。
- **屏幕自适应**：竖屏棋盘在上、横屏棋盘在左，小屏自动缩小，按钮永远按得到。
- **深浅色主题**：跟随系统 / 白天 / 黑夜 / 按时间自动切换。
- **全屏模式**：只留棋盘，专心下棋。

## 难度

围棋、五子棋、象棋、军棋都分**快 / 普通 / 强**三档。

- **快**：响应最快，适合随手走两手。
- **普通**：默认档，速度与棋力平衡。
- **强**：思考最久、下得最认真，适合想认真下完一整盘。

围棋另外可选三种规模的思考量，网络越强单步越慢；App 会为每档记住各自的设置，不用每次手动改。

## 安装

1. 从 **Releases** 下载最新安装包。
2. 系统提示「未知来源」时允许安装。
3. 首次启动会加载当前所选规模，稍等几秒即可开始。

安装包约 120 MB，因为多种规模的棋力数据都打包在内，装的时候会稍慢一点。
